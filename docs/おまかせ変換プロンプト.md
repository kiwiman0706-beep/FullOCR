# お任せ一括変換プロンプト（Claude Code に貼るだけ）

自炊PDFの入ったフォルダとこのリポジトリを Claude Code に渡し、下の本文をそのまま
貼り付けて使う。**重い変換は決定的処理（トークン0）で放置、Claudeが働くのは失敗本の
対応だけ**——という一番安い動き方をさせるためのプロンプト。

---

## 使い方（3ステップ）

1. Claude Code を、このリポジトリ（FullOCR）のフォルダで開く。
2. 変換したい自炊PDFのフォルダを用意する（例: `D:\jisui\books`）。
3. 下の「プロンプト本文」をコピーし、`{BOOKS}` を実際のフォルダパスに置き換えて送る。

事前に一度だけ環境を整えておく（別スレッドでも可）:

```powershell
cd <このリポジトリ>
uv pip install -e ".[dev,gui,pdf,docling,llm]"
fullocr init-config fullocr.config.json   # Geminiキーを使うならここに入れる
```

---

## プロンプト本文（ここから下をコピー）

```
このリポジトリは FullOCR（自炊PDF → Obsidian用Markdown 変換ツール）です。
CLAUDE.md を読んで構成を把握してから、次の方針で一括変換をお願いします。

【最重要・トークン節約の原則】
- 変換そのものは決定的処理（OCR/レイアウト/レンダリング）でトークンを使いません。
  だから変換の進捗を1冊ずつ見張らないでください。1発のコマンドで投げて待つだけにする。
- ログは画面に垂れ流さず、必ずファイルへ。あなたが読むのは最後の「要約」と
  「失敗した本」だけ。成功した本の中身は開かないでください。

【手順】
1. まず設定を確認（fullocr.config.json が無ければ `fullocr init-config` で作る）。
2. 次のコマンドを1回だけ実行してください（{BOOKS} は変換対象フォルダ）:

     fullocr batch "{BOOKS}" -c fullocr.config.json

   これは1冊ごとの進捗を out/batch.log に書き、画面には
   「成功N / スキップ / 失敗M＋原因」の要約だけ出します。
   既に変換済みの本は自動スキップ、失敗した本はアプリ側で自動リトライ済みです。

3. コマンドが終わったら out/batch_report.json を読んでください。
   - failed が空なら、要約を報告して終了。全ページのMDを検算しないこと。
   - failed があるものだけ、その本について out/batch.log の該当行を確認し、
     原因を切り分けてください。よくある原因と対応:
       * ファイル名の記号/末尾スペース → safe_book_name で吸収済みのはず。
         それでも落ちるなら batch.py / config を確認。
       * PDFが壊れている/ページ0 → その本はスキップ扱いにして一覧に残す。
       * NDLOCR / Docling のコマンドが見つからない → 設定の command 行を確認。
     コードのバグが原因なら直して `fullocr batch ... --no-engines` で該当本だけ
     再構築し直す（OCRは再実行しない）。判断に迷う失敗は、勝手に直さず私に聞くこと。

4. 最後に、成功N/スキップ/失敗Mと、失敗が残った本の一覧（原因つき）だけ報告して
   ください。長いログの貼り付けは不要です。

【やらないこと】
- 変換の完了を1冊ずつポーリングして待つ（トークンの無駄）。
- 成功した本のMDを1ファイルずつ開いて確認する（検品は別途 qc で行う）。
- ネットに書籍データを送る（書誌メタはDB照合、LLMは任意のGeminiのみ）。
```

## なぜこれで安いのか

| 局面 | トークン |
|---|---|
| `fullocr batch` がCPUで変換している間（待機） | **0**（推論していない＝課金なし） |
| 成功した本 | **0**（開かない・要約だけ） |
| 失敗した本の原因調査・修正 | ここだけClaudeが働く |

ポイントは **`fullocr batch` が進捗をログ「ファイル」に逃がし、失敗だけを
`out/batch_report.json` に構造化して残す**こと。だからClaudeは膨大なOCRログを
コンテキストに読み込まずに済み、例外処理にだけトークンを使えます。

## 関連コマンド

```
fullocr batch ./books -c fullocr.config.json          # お任せ一括変換
fullocr batch ./books --no-engines                    # コード修正後に下流だけ再構築（PDCA）
fullocr eval work/                                     # 目次精度の物差し（PDCAのC）
```
