# FullOCR ページアンカー仕様 `fullocr-1`

MarkdownとそのもとになったPDFの**ページ対応**を、Markdownのアウトライン（見出し構造）
を一切汚さずに埋め込むためのフォーマット。MDリーダー（dsbooks 等）が「いまMDで読んで
いる位置」から「原PDFの該当ページ」へワンタップで切り替えるために使う。

- 生成側: FullOCR（`RenderConfig.page_anchors=True`）
- 消費側: dsbooks など任意のMDリーダー
- バージョン識別子: **`fullocr-1`**（front-matter の `page_anchors` に入る）

---

## 1. 設計方針

| 要件 | 解決 |
|---|---|
| アウトラインを汚さない | 見出しに番号を足さず、**HTMLコメント**を独立行で置く |
| あらゆるMDレンダラで不可視 | `<!-- ... -->` はCommonMark準拠レンダラで非表示 |
| パースが簡単 | 1行1マーカー・固定の正規表現で抽出可能 |
| 実PDFへ確実に飛べる | 物理ページ番号を必須で持つ（`#page=N` で開ける） |
| 「本の実ページ番号」も扱える | 印刷ページ番号を任意で併記＋オフセット宣言 |

「本の実ページ番号 vs PDFのページ番号」問題は、**両方を持つ**ことで解決する。
飛ぶときは物理ページ（確実）、表示するときは印刷ページ（人間が認識する番号）。

---

## 2. マーカー構文（本文中）

各PDFページの**最初の可視ブロックの直前**に、独立した1行として挿入される。

```
<!-- fullocr:page pdf=23 print="15" -->
```

### 属性

| 属性 | 必須 | 意味 |
|---|---|---|
| `pdf` | **必須** | 原PDFの物理ページ番号（**1始まり**）。PDFビューアの `#page=N` に直接渡せる。常に存在。 |
| `print` | 任意 | そのページに印刷されていたページ番号（柱・ノンブルのOCR結果）。算用数字なら正規化済み文字列（`"15"`）、前付けはローマ数字（`"iv"`）。拾えなければ属性ごと省略。 |

### 抽出用の正規表現（リファレンス）

```regex
<!--\s*fullocr:page\s+pdf=(\d+)(?:\s+print="([^"]*)")?\s*-->
```

- グループ1 = `pdf`（整数）
- グループ2 = `print`（無ければ空/None）

### 保証・約束事

- マーカーは**必ず独立行**。前後は空行で区切られる。
- `pdf` は文書内で**単調増加**（1,2,3…）。欠番はありうる（白紙や処理除外）が逆転はしない。
- 隠しページ（印刷目次を `%%…%%` で隠す設定でも）マーカーは**コメント化せず常に出す**。
  → 目次ページ付近に読書位置があっても対応ページへ飛べる。
- 見出し行（`#`）には**絶対に混ざらない**。アウトライン抽出は従来どおりで良い。

## 3. front-matter 宣言（`00_index.md` 冒頭）

```yaml
---
title: 神経内科の教科書
pages: 452
page_anchors: fullocr-1        # ← このスキームで埋め込み済み、の宣言
pdf_file: 神経内科の教科書_text.pdf   # 原PDFのファイル名（同じフォルダに同梱）
page_offset: 8                 # pdf_page = printed_page + offset（確信がある時だけ）
tags: [fullocr]
---
```

| キー | 意味 |
|---|---|
| `page_anchors` | スキーム識別子。これがあればリーダーはアンカー対応と判断。無ければ非対応MDとして従来表示。 |
| `pdf_file` | 原PDFのファイル名。アンカーの `pdf=N` と組み合わせて開く先。 |
| `page_offset` | 算用数字ノンブルの最頻差。`印刷ページ = pdf - offset`。**3ページ以上で一致した時だけ**出力（自信がない時は出さない）。 |

> 注意: MDが章ごとに複数ファイルに分割される場合、front-matter は `00_index.md` にのみ付く。
> 本文ファイル（`01_*.md` 等）にはマーカーだけが入る。リーダーは `00_index.md` の宣言を
> 「その本（フォルダ）全体の設定」として扱うこと。

## 4. リーダー側（dsbooks）実装ガイド

### 4-1. 読み込み時
1. `00_index.md` の front-matter に `page_anchors: fullocr-1` があるか確認。無ければ従来のMD表示。
2. `pdf_file` と `page_offset`（あれば）を保持。
3. 本文を走査し、全マーカーを **(行位置/文字オフセット, pdf, print)** の配列にする（出現順＝昇順）。

### 4-2. 「原文を見る」への切り替え
- 現在の読書位置（画面最上部の行など）**以下で直近**のマーカーを二分探索で引く。
- そのマーカーの `pdf=N` を使って `pdf_file` を `#page=N` で開く。
  （PDF.js なら `?page=N` / `#page=N`、ネイティブビューアなら該当APIへ）

```
現在位置 ──▶ 直前のアンカー(pdf=N) ──▶ pdf_file を N ページで開く
```

### 4-3. 「現在ページ」の表示（任意）
優先順位で人間向けの番号を出す:
1. 直近マーカーに `print` があれば **それをそのまま**（例: `p.15`、`p.iv`）
2. 無く `page_offset` があれば `printed = pdf - offset` を計算して表示
3. どちらも無ければ `p.N（PDF通し）` とフォールバック表示

### 4-4. 逆方向（PDF→MD）も作れる
PDFのページ `N` を見ているとき、`pdf <= N` の直近マーカー位置へMDをスクロールすれば、
PDF→MDの相互ジャンプになる。

## 5. エッジケースと取り決め

| ケース | 挙動 |
|---|---|
| 柱/ノンブルが無いページ | `print` 省略。`pdf` は必ずある。offset があれば計算表示でカバー。 |
| 前付け（ローマ数字） | `print="iv"` のように小文字ローマ字で保持。offset計算には使わない。 |
| 白紙・図版で番号なし | `print` 省略。`pdf` は連番で振られる。 |
| 1スキャン＝見開き2ページ（2up） | 現仕様は **1 `pdf` = 1画像ページ**。2upは1アンカーに1番号（左右の区別は持たない）。自炊は単ページ化推奨。 |
| OCR誤読で印刷番号が変 | `print` は参考値。飛び先は常に `pdf`（物理）なので誤読の影響を受けない。 |
| offset がページ途中で変わる（合本等） | front-matter の単一 `page_offset` は出さない（最頻値が3未満なら省略）。各マーカーの `print` を正とする。 |

## 6. 最小サンプル

`00_index.md`:
```markdown
---
title: 神経内科の教科書
page_anchors: fullocr-1
pdf_file: 神経内科の教科書_text.pdf
page_offset: 8
tags: [fullocr]
---
# 神経内科の教科書
## 目次
- [[01_第1章 総論#第1章 総論|第1章 総論]]
```

`01_第1章 総論.md`:
```markdown
<!-- fullocr:page pdf=9 print="1" -->

# 第1章 総論

神経学的診察の基本は……

<!-- fullocr:page pdf=10 print="2" -->

意識障害は救急で最も……
```

→ 「第1章 総論」を読んでいる位置で「原文」を押すと、`神経内科の教科書_text.pdf` の
**9ページ目**（＝印刷1ページ）が開く。表示は `p.1`。

## 7. 生成側（FullOCR）メモ

- 有効化: `RenderConfig.page_anchors=True`（GUIの設定ドロワー / `fullocr.config.json`）。
- `pdf` は IR の `Page.number`。`print` は `PAGE_HEADER`/`PAGE_FOOTER` ブロックのOCRテキスト
  から算用数字/ローマ数字トークンを拾う（`render/markdown.py:_detect_nombre`）。
- `page_offset` は算用数字ノンブルの `pdf - printed` 最頻値（3ページ以上一致時のみ）。
- 既存の `pdf_page_links`（見出しに可視リンクを足すObsidian向け）と**併用可**。
  dsbooks 用には `page_anchors` だけで十分（不可視・全ページ）。

バージョンを増やす時は識別子を `fullocr-2` に上げ、本ファイルに差分を追記すること。
`fullocr-1` の `pdf` 必須・`<!-- fullocr:page ... -->` 構文は後方互換に保つ。
